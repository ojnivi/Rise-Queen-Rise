# Rise Queen Rise — Content Pack

Organized Clean Rise / Rise Queen Rise materials for Lady Butterfly Designs.

## Canonical day-by-day
Use `day-by-day/` (Days 01–30) and `calendar/30-day-lady-butterfly-prompt-calendar.md`.

## Structure
- `mission/` — purpose & spiritual movement framing
- `queens/` — emotional season archetypes (Bloom Queen, etc.)
- `calendar/` — full 30-day Lady Butterfly calendar
- `day-by-day/` — one file per day + master index
- `series/know-your-worth/` — quote cards + Leonardo prompts
- `prompts/` — floating-word and other prompt banks
- Older drafts kept at folder root for reference
